# Amazon Web Services (AWS) Research Report

## Brief Overview

Amazon Web Services (AWS) is a comprehensive and broadly adopted cloud platform, offering over 200 fully featured services from data centers globally. Launched in 2006, AWS is the market leader in cloud computing, providing infrastructure services like compute, storage, and databases to millions of customers worldwide. AWS is recognized for its extensive service catalog and mature ecosystem, making it the most popular choice for businesses of all sizes.

## Global Infrastructure

AWS has the most extensive global infrastructure, comprised of 32 geographic Regions and 102 Availability Zones worldwide. Each Region consists of multiple isolated Availability Zones connected through low-latency networks, ensuring high availability, fault tolerance, and scalability. AWS continues to expand its global presence with plans for new Regions in emerging markets to better serve customers globally.



## Cloud Management Console

The AWS Management Console is a web-based interface for accessing and managing all AWS services and resources. It provides a central hub for monitoring, configuring, and automating cloud infrastructure. The console features a customizable dashboard, resource management tools, and integrated monitoring capabilities to simplify operational tasks for cloud administrators.



## Four Core Services

### 1. Amazon Elastic Compute Cloud (EC2)
A web service that provides secure, resizable compute capacity in the cloud. EC2 allows users to launch and manage virtual servers (instances) with various operating systems and configurations. It offers features like Auto Scaling and Elastic Load Balancing to handle variable workloads.

### 2. Amazon Simple Storage Service (S3)
An object storage service built to retrieve any amount of data from anywhere. S3 is known for its industry-leading scalability, data availability, security, and performance. It offers multiple storage classes for different use cases, from frequently accessed data to long-term archival.

### 3. Amazon Virtual Private Cloud (VPC)
A service that lets you provision a logically isolated section of the AWS Cloud where you can launch AWS resources in a virtual network that you define. VPC provides complete control over your virtual networking environment, including IP address ranges, subnets, route tables, and network gateways.

### 4. AWS Identity and Access Management (IAM)
A web service that helps you securely control access to AWS resources. IAM enables you to manage users, groups, roles, and their permissions. It provides fine-grained access control and supports multi-factor authentication for enhanced security.

## Three Advantages

1. **Broadest Service Catalog** - AWS offers the widest selection of services, tools, and features to support virtually any cloud workload, from compute and storage to AI and IoT.

2. **Global Reach and Scalability** - Its vast global infrastructure enables businesses to scale applications and serve users worldwide with low latency and high availability.

3. **Mature and Trusted Platform** - As the pioneer in cloud computing since 2006, AWS has a long history, extensive documentation, and a large, active community providing support and resources.

## Typical Enterprise Use Cases

- **Migration and Modernization** - Migrating and modernizing legacy IT infrastructure to improve agility and reduce costs
- **Web Applications** - Building highly scalable and available web applications and e-commerce sites
- **Big Data Analytics** - Supporting big data analytics and machine learning projects using services like EMR and SageMaker
- **Container Orchestration** - Running containerized workloads with services like Amazon EKS (Elastic Kubernetes Service)
