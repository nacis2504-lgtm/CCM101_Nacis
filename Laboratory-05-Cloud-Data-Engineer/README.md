# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focused on understanding and working with cloud-based storage, particularly object storage through MinIO. The activities included setting up MinIO with Docker, configuring its access settings, opening the Web Console, creating a storage bucket, and managing files. The laboratory provided hands-on experience with cloud data storage in a Linux environment.

## Objectives

- Learn the fundamentals of cloud storage.
- Understand how object storage works.
- Set up MinIO using Docker.
- Use environment variables to configure MinIO.
- Access the MinIO Web Console through a web browser.
- Create and manage an object storage bucket.
- Upload files to a MinIO bucket.
- Check the status of a Docker container.
- Practice documenting cloud-related activities.

## Key Learnings

This laboratory helped me understand how object storage can be used to organize and manage different types of files. I learned how Docker can be used to run MinIO and how environment variables can be used to configure the server.

I also learned how to access the MinIO Web Console, create a bucket, and upload objects. In addition, I practiced using Docker commands in Ubuntu and improved my troubleshooting and technical documentation skills.
