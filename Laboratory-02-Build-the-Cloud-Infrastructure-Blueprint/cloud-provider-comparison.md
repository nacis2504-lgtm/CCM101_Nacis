# Cloud Provider Comparison: AWS vs. Azure vs. GCP

## Core Infrastructure Service Comparison

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon Elastic Compute Cloud (EC2), AWS Lambda, Amazon ECS/EKS.  | Azure Virtual Machines, Azure Functions, Azure Container Instances, Azure Kubernetes Service (AKS). | Compute Engine, Cloud Functions, Google Kubernetes Engine (GKE), Cloud Run. |
| **Storage** | Amazon Simple Storage Service (S3), Amazon Elastic Block Store (EBS), Amazon Elastic File System (EFS). | Azure Blob Storage, Azure Disk Storage, Azure Files.  | Cloud Storage (object storage), Persistent Disk, Filestore  |
| **Networking** | Amazon Virtual Private Cloud (VPC), Elastic Load Balancing (ELB), AWS Direct Connect. | Azure Virtual Network (VNet), Azure Load Balancer, Application Gateway, Azure VPN Gateway. | Virtual Private Cloud (VPC), Cloud Load Balancing, Cloud CDN, Cloud Interconnect.  |
| **Identity and Access Management (IAM)** | AWS Identity and Access Management (IAM) | Microsoft Entra ID (formerly Azure Active Directory), Azure Role-Based Access Control (RBAC). | Google Cloud IAM, Identity-Aware Proxy (IAP)
